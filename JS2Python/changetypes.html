Most of the changes made in removing the transformations can be categorized as below.

Capitalization (A)
For most of the datasets, all text was capitalized. During transformation, this was changed to lower case, with proper nouns being capitalized. This has been removed and text data will ALL be capitalized.

Zip Codes (B)
For zip codes that have 4 digit extensions, the 4 digit extensions were removed and stored in a separate field. This is no longer being done, the extensions are now part of the zip code, when they exist, and the field that contained the extension has been deleted.

Character Removal (E)
For some fields, characters were removed in order to convert the field from a string to a number. Some examples would be hyphens and commas. These are no longer removed.

True/False (C)
Fields that contained values such as Y/N and Yes/No were change to True/False. The original Y/N,Yes/No values will now be found for these fields.

Phone Numbers (D)
All non-digit characters were removed from phone numbers in order to make these only digits. This included removing ()-. and white spaces. These characters are no longer being removed.

Web Addresses (F)
For web addresses, http:// and https:// were removed, but no longer will be. As these are text fields, they were changed to lower case, but will not be all capitalized.

Date/Time (G#)
There are multiple ways that differences will be found between the older, transformed dates and what is now being transmitted. Note that in all cases, what is being transmitted is correct!
  • Simple Format Difference (G1) - In these, the Dates are the same, but they are simply formatted differently. This would also include removing extraneous time stamps that are often added by system software when a time was not recorded in the data.
  • Date was indadvertantly changed to an incorrect date (G2)
  • Date incorrectly changed to missing (G3)

City (H)
City names have been corrected/changed in several ways. The first is simply changes in capitalization (Type A). The second is when city names were mis-spelled and they are corrected. These will no longer be corrected, so there will be cases where the city names are mis-spelled, sometimes drastically.

Empty Fixes (I)
The were cases where, because of changes to data and/or software, the intended Transformations resulted in empty strings being archived to CIM. These have now been fixed and the empty strings are now replaced with the correct value(s). Note that Date chantes, G3 is a subset of these issues specific to dates. Also, in some cases, no all values for a field were affected and in other cases, all values for the field were affected.

As noted, each affected dataset has a section below this one that describes in detail what was changed for that dataset. The codes below are used to describe field specific changes.
